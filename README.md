A deterministic Python program (stdlib only) that renames Mercury "The Two-Year Day" — one sunrise-to-sunrise lasts two whole Mercurian years, the worst jet lag in the solar system. It writes the one-line rename to `/output/entry.txt` for make.fun's "Rename the Planet" bounty.

## Run it

```sh
python3 main.py
```
